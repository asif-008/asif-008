# Asif Anjum Khan

I studied computer science at the University of Saskatchewan in Canada and completed an MBA in Management Consultancy in Malta. I enjoy building tools that help me investigate a question, whether that means running a software experiment or tracing a result back to the data behind a dashboard.

## Software engineering research

As a research assistant in the University of Saskatchewan’s Software Research Lab, I used Python to automate experiments involving the GitHub and ChatGPT APIs. I worked with Docker, Indri and Bench4BL on bug localization, which asks whether a bug report can help identify the source files that need attention. I also explored code clone detection using a QUBO formulation on D-Wave.

## Selected projects

- **[IMDb genre and ratings dashboard](https://github.com/asif-008/Data-Analysis-of-The-Most-Voted-Titles-on-IMDB)** — I collected data on 2,500 widely rated movies and TV series, prepared title and genre tables, and built a Tableau dashboard to explore how genres, ratings and release years vary across the sample.
- **[Pizza shop sales simulation](https://github.com/asif-008/restaurant_data_analytics_with-sample_data)** — I built a Python generator for a fictional pizza shop and analyzed its transactions in Excel. The case study follows one assumption about the menu through to the share of cheese pizzas sold in the simulation.
